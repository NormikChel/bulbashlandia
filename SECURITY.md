# Политика безопасности

## Поддерживаемые версии

Проект находится в активной разработке. Обновления безопасности выпускаются
для последней версии в ветке `main`.

| Версия | Поддержка |
|--------|-----------|
| `main` | ✅ Да |
| Старые теги | ❌ Нет |

## Как сообщить об уязвимости

**Пожалуйста, не создавай публичный Issue для сообщений об уязвимостях.**

Вместо этого используй один из способов:

1. **GitHub Security Advisories** (предпочтительно):
   [Создать приватный отчёт](https://github.com/NormikChel/bulbashlandia/security/advisories/new)
2. **Email**: `nenormikchel@gmail.com`

В отчёте укажи:

- тип уязвимости (XSS, SQL-инъекция, CSRF, path traversal и т.д.);
- полный URL или путь к файлу, где воспроизводится;
- шаги воспроизведения;
- возможное влияние;
- если знаешь — предложение по исправлению;
- твоё имя/ник для указания в благодарностях (по желанию).

## Что можно ожидать

- **Подтверждение** получения отчёта — в течение 72 часов.
- **Первичная оценка** — в течение 7 дней.
- **Исправление** — зависит от серьёзности:
  - критично: 1–3 дня;
  - высокий риск: 1–2 недели;
  - средний/низкий: по мере возможности.
- **Публичное раскрытие** — после выпуска исправления, по согласованию с тобой.

## Область действия (scope)

**В зоне ответственности:**

- Код в этом репозитории (`app.rb`, `lib/`, `models/`, `views/`).
- Логика i18n, роутинг, шаблоны.
- Service Worker и PWA-логика.
- Публичный сайт: `https://bulbashlandia.onrender.com`

**Вне зоны ответственности:**

- Уязвимости в сторонних библиотеках (Lenуs, BVI) — сообщай их авторам.
- Уязвимости в инфраструктуре Cloudflare / Render / GitHub.
- Социнженерия, DoS-атаки, спам.
- Проблемы с TLS/сертификатами.
